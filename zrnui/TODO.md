# Отладочные значения в window.c — убрать перед выпуском

- **`ZRNUI_DUMP`** — дамп буфера окна в PPM (`window_dump()`, ветки в `present_gl()`
  и `present()`, поля `dumped_sw`/`frames_sw`; 60-й кадр, до свопа). Когда-то был нужен для
  сверки буфера реального окна с эталонным headless-рендером (скриншот композитора не
  показывает, что именно нарисовал пайплайн). Выпилить целиком, вместе с ветками чтения.

- **`scale_report()`** — строка лога «что дал скейл» (env, preferred_scale композитора,
  размер буфера, есть ли viewport). Тоже отладка. Перед выпуском: убрать, или перенести
  под общий `$ZRNUI_LOG`-флаг, если диагностика скейла пригодится дальше.

# Переменные окружения (оставить, но задокументировать в README)

| переменная | делает |
|---|---|
| `$ZRNUI_SCALE`  | оверрайд скейла UI (debug only): сетка разметки = окно / скейл; без него — `wp_fractional_scale_v1.preferred_scale` композитора, владелец скейла на мобильной оболочке |
| `$ZRNUI_ANIMATION_SPEED` | множитель скорости всех анимаций (0.5 — вдвое медленнее, 2 — вдвое быстрее); по умолчанию 1.0. Задержка подсказок (500 мс) и время на часах идут в реальном времени. |

# Модель скейлинга (сделано)

- Окно всегда fullscreen: размер даёт configure композитора, приложение размером не владеет
  (`ZRNUI_WINDOW` удалена).
- Скейл UI = preferred_scale оболочки: layout живёт в сетке W/s × H/s (480-грид телефона),
  painter рисует ×s, буфер — W × плотность. Плотность (чёткость) и скейл UI разведены
  (`zrn_root_set_density` / `Zroot_set_scale`), painter-scale = их произведение.
